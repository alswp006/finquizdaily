# FinQuizDaily

앱인토스 (Vite + React + TDS) 매일 3문제씩 풀며 금융 상식을 키우는 데일리 금융 리터러시 퀴즈, 랭킹과 스트릭으로 습관화 금융 지식이 필요하다고 느끼지만 딱딱한 교육 콘텐츠는 진입장벽이 높고, 재미있게 매일 학습할 수단이 부족함

## Tech Stack

- React 18.0.0
- TypeScript
- Vitest
