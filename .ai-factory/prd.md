# FinQuizDaily

## Platform
앱인토스 (Vite + React + TDS)

## One-liner
매일 3문제씩 풀며 금융 상식을 키우는 데일리 금융 리터러시 퀴즈, 랭킹과 스트릭으로 습관화

## Problem
금융 지식이 필요하다고 느끼지만 딱딱한 교육 콘텐츠는 진입장벽이 높고, 재미있게 매일 학습할 수단이 부족함

## Target Users
금융 지식을 쌓고 싶은 2030 사회초년생 및 재테크 관심층

## Core Features
1. 매일 3문제 금융 퀴즈(카드뉴스 형식)
2. 정답률 기반 스트릭/뱃지 시스템
3. 친구와 점수 비교 공유 카드
4. 오답노트 자동 정리
5. 리워드 광고 시청 시 심화 해설 + 추가 문제 5개 언락
6. 주간 랭킹 리더보드

## Monetization
- Model: ads
- Estimated MRR: 약 39만원
- Reasoning: 매일 반복 방문 습관과 결과 공유 후 심화 콘텐츠를 리워드 광고로 게이팅해 높은 전환율 기대, 퀴즈 목록에 배너 상시 노출
